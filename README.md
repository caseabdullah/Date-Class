# 📅 Custom Date Class Using C++ | Date Management & Formatting

## 📌 About the Project

This project implements a custom **Date class in C++** to manage dates using day, month, and year.

It provides date validation, leap year calculation, date setters and getters, and multiple date formatting options using a custom String class.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Encapsulation
  - Static Data Members
  - Constructors
  - Getters and Setters
  - Leap Year Calculation
  - Date Validation
  - Custom String Class

## ⚙️ Implemented Features

### 1. Date Construction & Management
- Default Constructor
- Parameterized Constructor
- Set Date
- Set Day
- Set Month
- Set Year
- Get Day
- Get Month
- Get Year

### 2. Date Validation & Calculation
- Check Leap Year
- Store Maximum Days in Each Month
- Store Month Names
- Handle Different Month Lengths

### 3. Date Formatting
- Print Date in Format 1
- Print Date in Format 2
- Print Date in Format 3
- Get Date as a String in Format 1
- Get Date as a String in Format 2
- Get Date as a String in Format 3
